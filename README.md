# Отчет по лабораторной работе №4: Написание Unit тестов

**1. Цели и задачи тестирования**
*   **Цель:** Проверить правильность работы функций для расчета площади и периметра фигур с помощью автоматических unit-тестов.
*   **Задачи:**
    *   Убедиться, что формулы считают верно при обычных значениях.
    *   Проверить работу программы с нулем (граничное значение).
    *   Проверить, что программа выдает ошибку (`ValueError`), если передать отрицательные числа, и ошибку (`TypeError`), если передать текст вместо числа.

**2. Описание тестируемого продукта**
Программа состоит из двух файлов на языке Python:
*   `rectangle.py` — вычисляет площадь и периметр прямоугольника.
*   `circle.py` — вычисляет площадь и периметр круга.
Программа принимает целые и дробные числа, а если передать ей что-то другое, она должна блокировать такие данные.

**3. Область тестирования**
Тестируются все четыре математические функции внутри файлов `rectangle.py` и `circle.py`. Нагрузка или скорость работы программы в этой лабораторной не проверяются.

**4. Стратегия тестирования**
*   Используется встроенная библиотека Python `unittest`.
*   Проверяются три основных сценария: нормальные данные, ноль и заведомо неверные данные (негативные тесты).
*   Для круга применяется специальный метод `assertAlmostEqual`, чтобы тесты не ломались из-за микроскопических погрешностей при умножении на число Пи.

**5. Таблица с ручными тест-кейсами**

| Номер | Наименование теста | Шаги воспроизведения | Ожидаемый результат | Фактический результат | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | Нормальные числа (прямоугольник) | Вызвать `rectangle.area(10, 10)` | Возвращается `100` | `100` | Успешно |
| 2 | Сторона равна нулю (прямоугольник) | Вызвать `rectangle.perimeter(10, 0)` | Возвращается `20` | `20` | Успешно |
| 3 | Отрицательное число (прямоугольник) | Вызвать `rectangle.area(-5, 10)` | Вылетает ошибка `ValueError` | `ValueError` | Успешно |
| 4 | Передача строки (прямоугольник) | Вызвать `rectangle.perimeter("10", 10)` | Вылетает ошибка `TypeError` | `TypeError` | Успешно |
| 5 | Нормальные числа (круг) | Вызвать `circle.area(10)` | `314.15...` (округление до сотых) | `314.15...` | Успешно |
| 6 | Радиус равен нулю (круг) | Вызвать `circle.perimeter(0)` | Возвращается `0` | `0` | Успешно |
| 7 | Отрицательный радиус (круг) | Вызвать `circle.perimeter(-5)` | Вылетает ошибка `ValueError` | `ValueError` | Успешно |
| 8 | Передача строки (круг) | Вызвать `circle.area("10")` | Вылетает ошибка `TypeError` | `TypeError` | Успешно |

**6. Критерии приемки**
*   Функции выдают правильные ответы по математическим формулам.
*   Код защищен от минусовых значений и неверных типов данных (выдаются правильные ошибки).
*   В консоли все тесты проходят со статусом `OK`.
*   Исходный код загружен на GitHub, в истории коммитов видно процесс добавления тестов.

**7. Ожидаемые результаты**
При запуске команды `python -m unittest` терминал покажет успешное выполнение всех тестов. Логика программы работает без сбоев, некорректные данные правильно блокируются, а код сохранен в репозитории.
